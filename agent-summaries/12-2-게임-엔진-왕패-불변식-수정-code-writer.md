# 게임 엔진 왕패 불변식 수정 및 테스트 보강 (code-writer)

## 수정 사실
- `game.ts` `drawRinshan`: 깡 후 영상패를 뽑을 때 산패 마지막 장을 왕패 끝에 append하던 방식(왕패 15장, 뽑힌 영상패 중복)을 폐기하고, 뽑힌 슬롯 `deadWall[kanSeats.length-1]`을 산패 마지막 장으로 제자리 교체하도록 변경. 왕패 14장, 중복 없음, 전체 136장, 도라/뒷도라/다음 영상패 인덱스가 불변. 산패 소진 시 깡 불가 규칙은 그대로.
- 이전 요약 문서(`12-1-게임-진행-엔진-봇-구현-code-writer.md`)의 "왕패 뒤로 이동/머리박음" 서술은 과거 기록이므로 수정하지 않았고, 이 문서가 정정본이다.
- 용어 정정: "머리박음" -> 실제 동작인 "더블론 허용, 본장/리치봉은 첫 화료자(버린 사람 기준 순서)만 수령" (game.ts 주석, game.test.ts 제목).

## 테스트 추가/수정
- game.test.ts: 대명깡 테스트의 왕패 길이 단언을 15 -> 14로 정정하고 슬롯 교체 단언 추가. 안깡 2회 후 왕패 14장/136장/기존 표시패 불변 테스트 추가.
- game.test.ts: 리치 후 영구 후리텐(비리치 대비), 후리텐 츠모 가능, 자 츠모 지불(친 2배, 본장, 리치봉), 친 론 렌짱 테스트 추가.
- sim.test.ts: 시드 고정 무작위 합법 행동 퍼즈(24게임, 게임당 최대 4국). 구종구패는 희귀해 선택 횟수를 강제하지 않음(game.test.ts에서 검증).
