### yakuman.test.ts "여러 해석 중 최고 배수 채택 (bestYakuman)" (6개)
`yakumanCandidates`의 배수 집합과 `bestYakuman` 결과를 직접 단언한다. 삭수 222333444s는 각자 3개로도 순자 234s 3개로도 읽혀서 해석이 갈린다. 녹일색은 분해와 무관하게 성립하므로 후보가 항상 2종류 이상 나오고 배수만 갈린다. 최소 배수를 고르면 아래 기대값이 모두 어긋난다.
- `222333444s 666s 88s` 츠모 2s: 각자 해석 = 녹일색 + 스안커(샤보 완성) 2배, 순자 해석 = 녹일색 1배. 후보 배수 [1,2], 채택 2배, 총점 64000 (친 32000 + 자 16000 x 2).
- 같은 손패 론 2s: 각자 해석은 샤보 론이라 스안커가 깨짐. 후보 [1], 32000.
- 같은 손패 츠모 8s: 각자 해석 = 스안커 단기(2) + 녹일색(1) = 3배, 순자 해석 1배. 후보 [1,3], 총점 96000.
- 같은 손패 론 8s: 단기는 론이어도 안커 4개 유지. 후보 [1,3], 96000.
- `222333444s 888s 66s`: 츠모 4s는 [1,2] 64000, 츠모 6s는 [1,3] 96000, 론 4s는 [1] 32000.
- 안깡 6666s + `222333444s 88s`: 츠모 2s는 [1,2] 64000, 츠모 8s는 [1,3] 96000, 론 2s는 [1].

참고: 같은 분해 안에서 대기 해석만 갈려 스안커가 깨지거나 안 깨지는 손패는 만들 수 없었다. 스안커 분해(각자 4개 + 대자)에서는 당첨패가 속한 멘츠/대자가 하나뿐이라 대기 해석이 하나로 정해진다. 그래서 갈림은 분해(각자 vs 순자) 차이와 론/츠모 차이로 구성했다.

### game.test.ts "리치 후 역만 화료" (5개)
상태는 기존 `build` 헬퍼로 구성했고, 모든 케이스에서 점수 합 + 리치봉 x 1000 = 100000을 확인했다.
- 친 국사무쌍 13면 리치 츠모 (본장 1, 리치봉 2): 기본점 16000, 올 32100 x 3 = 96300 + 리치봉 2000. deltas [98300, -32100 x 3], dora 0, han 0, 역은 국사무쌍 13면 대기뿐. 도라/뒷도라 표시패는 7z라 도라가 백이고 손패에 백 1장이 있지만 반영되지 않는다.
- 자 국사무쌍 단일 대기(중 대기) 리치 츠모 (본장 2, 리치봉 1): 기본점 8000, 친 16200 + 자 8200 x 2 = 32600 + 1000. deltas [-16200, 33600, -8200, -8200].
- 자 국사무쌍 13면 리치 론 (본장 3, 리치봉 1): 64000 + 900 + 1000 = 65900 수령, 버린 친은 64900 지불.
- 친 스안커 리치 츠모 (리치봉 1): 도라 표시패 4s(555s 3장) + 뒷도라 표시패 2p(333p 3장)를 일부러 배치해 일반 화료라면 도라 6이지만 dora 0, 올 16000 x 3 = 48000 + 1000.
- 자 스안커 리치 츠모: 친 16000 + 자 8000 x 2 = 32000 + 1000 (같은 도라/뒷도라 배치).
