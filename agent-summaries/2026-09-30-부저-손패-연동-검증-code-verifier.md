# 부저 손패 연동 검증 (code-verifier)

## 수행
- npx vitest run: 12 파일 293 테스트 전부 통과. npx tsc --noEmit: 오류 없음.
- meld/agari/yaku/score/dora 소스를 리뷰하고 임시 프로브 테스트(삭제 완료)로 실입력 검증.
- 프로브 확인: 안깡 론 멘젠 +10 유지(중장 안깡 50부, 요구 안깡 70부), 안깡 츠모 40/60부, 쿠이핑후 론/츠모 30부,
  더블동 안깡 70부, 4멜드 단기/대자, 삼안커(안깡 산입, 론 샤보 제외, 츠모 산입), 도라 깡 4장, 멜드 5개/장수 불일치 에러.
  모두 규칙과 일치.

## 발견 (버그/규칙 오류 없음)
- 사소: 멜드 5개 이상일 때 에러 메시지가 "-1장 손패" 식으로 부자연스러움 (yaku.ts assertHandSize, dora.ts collectTiles).
- 사소: detectYaku는 isConcealed=false + 부로 없음(정합성 오류)을 검증하지 않고 calculateScore만 던짐.
- 사소/문서화된 한계: 안깡 4개(스안커)는 역만이 아니라 삼안커 2판으로 계산.
- 테스트 부족(buro.test.ts): 부로 손패의 대기 부수(간짱/변짱/단기), 머리 역패 부수, 4멜드 점수 계산,
  안깡 츠모 부수, 부로 시 치토이츠 불성립의 score 경로 테스트가 없거나 약함.

## 결론
요구사항 대비 기능 통과. 프로브 파일은 삭제함.
