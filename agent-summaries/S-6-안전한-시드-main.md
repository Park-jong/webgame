# S-6 안전한 시드 (main 직접 작업)

S-5에서 `rng.ts`(crypto 기반 `secureRandom`)가 이미 구현되어 있어, S-6은 검증 테스트 추가로 마무리했다.

## 변경
- 신규 `packages/server/src/rng.test.ts` (6개)
  - `[0, 1)` 범위 20000회, 경계 입력(전부 0x00 → 0, 전부 0xFF → 1 미만)
  - `Math.random` 미호출 (spy로 `createGame(secureRandom)`까지 확인)
  - 10개 구간 균등성 (5만 회, 오차 400 이내)
  - `shuffleTiles` 결과가 136장 순열을 유지하고 호출마다 달라짐
  - 서로 다른 게임이 다른 배패를 받음 (고정 시드 아님)

## 결정
- 시드/RNG 상태는 `GameState`에 없고 서버 메모리의 RNG 클로저에만 있다. 어떤 메시지에도 실리지 않는다(S-3 뷰 금지 키 검사, S-5 오류 응답 수집으로 확인됨).
- 방 단위 시드 보관은 하지 않았다. 재현이 필요하면 `GameSessionOptions.rng`로 주입한다(테스트 전용).
