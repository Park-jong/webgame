# 튜토리얼 좌석별 기본 버림패와 쯔모기리/테다시 설명

## 변경 파일 (packages/web/src/tutorial/, 스타일 1곳)
- scenes.ts: `BASE_DISCARDS`(좌석별 4장, 쯔모기리 표기), `DORA_INDICATOR` 이동·export, `PondSeat`/`PondTile` 타입, 2단계 말풍선에 한 줄 추가(완료 조건·진행 로직 불변)
- TutorialPage.tsx: 모든 좌석에 기본 버림패 표시. 3단계는 상가 기본 4장 + 5통(5번째, 응답 대상 강조). 내 좌석은 기본 4장 + 방금 버린 패. 6~7단계(리치 상태)는 마지막에 리치 선언한 9삭을 남김
- boardInfo.ts: `.pond-entry.pond-tsumogiri`(쯔모기리), `.pond-entry:not(.pond-tsumogiri)`(테다시)를 패 단위 별도 info id로 부여. 종류별 첫 번째만 tabindex 0
- infoTexts.ts: `tsumogiri`, `tedashi` 추가, `pond` 문구 수정
- styles.css: `.tutorial-board .pond-entry[data-info]` 오프셋 0, 응답 대상 금색 윤곽 유지
- 공용 컴포넌트/core/server 수정 없음

## 좌석별 버림패 (* = 쯔모기리)
- 나: 9만, 남*, 중, 1통 (2단계에서 북* 추가, 6단계 이후 리치 9삭* 추가)
- 하가: 9삭, 중, 1통*, 9만
- 대면: 백*, 1만, 8통, 남
- 상가: 1삭, 서*, 9통, 발 (3단계에서 5통이 5번째)

## 설명 문구
- 버림패(강): "각자 앞에 버린 패를 버린 순서대로 늘어놓은 곳(강)입니다. 모두에게 공개되어 있어서, 상대가 무엇을 버렸는지 보면 무엇을 노리는지 짐작하는 단서가 돼요. 어두운 패와 밝은 패의 차이는 그 패를 눌러 보세요."
- 쯔모기리: "방금 뽑은 패를 그대로 버린 패입니다. 어둡게 표시해요. 뽑은 패를 바로 버리면 손패는 그대로 유지됩니다."
- 테다시: "손패에서 골라 버린 패입니다. 밝게 표시해요. 손패 구성이 바뀐 것이므로, 상대는 그 사람의 손이 어떻게 변하는지 읽을 수 있어요."

## 제약 확인
- 패 4장 이하: 손패+뽑은 패+5통+도라 표시패+모든 기본 버림패로 검증(scenes.test.ts). 북은 기본 버림패에 없음
- 후리텐 아님: 내 버림패(기본+북+9삭)와 6단계 화료패에 3삭 없음(테스트 추가). 4단계 후리텐 배지 없음 육안 확인
