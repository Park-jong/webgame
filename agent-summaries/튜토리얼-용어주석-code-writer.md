## 동작
- 표기 앞 글자가 한글/영숫자이면 제외(다른 낱말 일부 오탐 방지), 긴 표기 우선.
- 주석은 사전상 첫 등장 단계에서만, 그 단계 안에서는 화면 순서(말풍선 -> 보조 설명 -> 완료 문구) 첫 한 번만.
  이전 단계로 돌아가면 그 단계의 첫 등장 용어는 다시 보인다. 상태 저장 없음.
- 잘못 눌렀을 때 힌트(wrongHint)와 제목, 결과 카드는 주석하지 않음.
- 클릭은 연습 상태를 바꾸지 않고, 팝오버는 화면 설명과 하나만 열림(닫기/Esc/바깥 클릭).
- aria-label "'용어' 뜻 보기", 팝오버 role="dialog" 유지.

## 용어와 풀이 / 첫 등장 단계
| 용어 | 풀이 | 첫 등장 |
|---|---|---|
| 몸통 | 같은 패 3장, 또는 같은 종류의 연속된 숫자 3장 묶음 | 1 |
| 머리 | 같은 패 2장 묶음. 완성하려면 몸통 4개와 머리 1개 | 1 |
| 쯔모기리 | 방금 뽑은 패를 그대로 버리는 것 | 2 |
| 테다시 | 손패에 있던 패를 골라 버리는 것 | 2 |
| 치 | 왼쪽 사람이 버린 패로 연속된 숫자 3장 몸통을 만드는 것 | 3 |
| 펑 | 같은 패 3장 몸통(누가 버린 패든 가능) | 3 |
| 후로 | 치·펑·깡으로 남이 버린 패를 가져와 몸통을 공개하는 것 | 3 (완료 문구) |
| 멘젠 | 후로 없이 스스로 모은 상태. 후로하면 깨져 리치 불가 | 3 (완료 문구) |
| 리치 | 텐파이일 때 선언. 손패를 바꾸지 않는 대신 역이 생김 | 3 (완료 문구) |
| 텐파이 | 한 장만 더 오면 완성되는 상태 | 4 |
| 대기패 | 완성을 위해 기다리는 패 | 4 |
| 역 | 화료 조건. 하나도 없으면 화료 불가 | 5 |
| 츠모(쯔모, 츠모 표기 허용) | 내가 뽑은 패로 완성해 이기는 것 | 6 |
| 론 | 남이 버린 패로 완성해 이기는 것 | 6 |
| 화료 | 패를 완성해 이기는 것(쯔모 또는 론) | 6 |

도라·깡·유국은 튜토리얼 안내문에 나오지 않아 사전에 넣지 않았다(화면 설명 팝오버에는 기존 설명 있음).
